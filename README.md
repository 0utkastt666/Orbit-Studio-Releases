# ORBIT Studio

A FiveM asset studio for clothing and MLOs, made by Outkastt.

## Download

Get `ORBIT.Studio.Setup.<version>.exe` from the [latest release](https://github.com/0utkastt666/orbit-studio-releases/releases/latest) and run it. You only need to do this once. ORBIT Studio checks for updates by itself, shows **Update available** in the title bar when there is one, and restarts on the new version when you click **Restart to update**.

The installer is not code-signed, so the first time Windows may show "Windows protected your PC". Click **More info**, then **Run anyway**.
